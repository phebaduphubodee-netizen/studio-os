## 2. เครื่องมือ: audition ต้องวิ่งผ่าน build เท่านั้น

`--item-model=<index|kind>:<slug>` เขียน `model` ลง spec item ตอน runtime แล้วปล่อยให้ทุกด่านเดิม
(model_fit → sidecar scale → place_model → กฎ facing → D8) ทำงานตามปกติ

**ทำไมไม่สร้างเครื่องมือถ่ายภาพแยก:** รอบที่แล้วจ่ายค่านี้ไปแล้วเต็ม ๆ — สคริปต์ถ่าย candidate
render ทุก mesh ที่ import ส่วน build render เฉพาะชิ้นที่ผ่านด่าน สองตัวเลยไม่ตรงกันอยู่หนึ่งรอบเต็ม
**สิ่งที่ตาตัดสิน ต้องเป็นสิ่งที่ build ส่งออก**

เพิ่ม scale band 4 คลาส (bed_frame / nightstand / bench_seat / rug) พร้อมแกนวินิจฉัยใหม่
**`maxxy`** = ด้านนอนที่ยาวที่สุด — เพราะเตียงกับพรมวินิจฉัยด้วย *ผัง* ไม่ใช่ความสูง และแกน x/y ตรง ๆ
จะให้คำตอบต่างกันแค่เพราะคนอัปโหลดวางโมเดลคนละทาง (มีเทสต์พิสูจน์ว่าหมุน 90° แล้วผลเท่าเดิม
และยังจับ 0.0254× ได้ทั้งสองท่า)

## 3. ผล audition — ของจริงทั้งดีและร้าย

โหลด 10 ตัว **ผ่าน scale assertion ทั้ง 10** แล้วยัดเข้า build:

- **โต๊ะข้างเตียง ✅ ผ่านด่านทั้ง 3 ตัว** (scale 0.89–1.00)
- **เตียง ❌** `height mismatch — fits to 1090 mm vs the spec's 600 mm (1.82x)`
- **ม้านั่ง ❌** `aspect mismatch — fills only 35% (mesh 622x433 vs slot 498x1000 mm)`
- **พรม ❌** `aspect mismatch — fills only 55% (mesh 1613x2362 vs slot 3100x2500 mm)`

**และการซื้อโต๊ะข้างเตียงลบของที่เซ็นไว้ไปด้วยหนึ่งอย่าง** — โคมโดมทองเหลืองหายทั้งสองข้าง
เพราะตู้กับโคมอยู่ในฟังก์ชันเดียวกัน การเปลี่ยนตู้จึงลบ D3-3 (accent ทองเหลือง 10% และ practical
อุ่นดวงเดียวของห้อง) ไปเป็นผลข้างเคียงที่ไม่มีใครสั่ง → **แยกโคมออกมาเป็น `_nightstand_lamp`
หนึ่งชุด สองคนเรียก** และโคมนั่งบน **ผิวบนที่วัดได้จริง** ของตู้ที่ซื้อมา (R9: contact ไม่ใช่ z ที่พิมพ์)
ตู้สูงเท่าไรโคมก็ตามถูก ไม่ต้องกรอกเลขใหม่

## 4. ตาผมอ่านโต๊ะข้างเตียงทั้งสี่ (ยังไม่ผ่านตาพี่)

โคมกลับมาครบทั้งสามเลก **แต่ไม่มีตัวไหนชนะของที่ปั้นเอง**: ทั้งสามเป็นกล่อง 56 โพลี ไม่มี PBR
และที่สำคัญกว่า — **มันใส่วัสดุของตัวเองมา** ซึ่งชนกับ palette ที่เซ็น (D3-3 บอก matte-DARK,
D1-A ห้ามไม้โอ๊คก้อนที่ห้า) ตัว n2 ที่รูปทรงดีที่สุดกลับเป็นไม้อ่อน = ผิดข้อ D1-A ตรง ๆ

**นี่คือช่องที่ยังไม่มีกฎ**: ทางซื้อมี retint ให้เฉพาะคลาส `_UPHOLSTERED` — ตู้ไม้/ตู้ทึบยังไม่มี
นโยบายวัสดุ จึงมาทั้งสีของคนอื่น

## 5. สามข้อที่ตีตก — ทำไมผมไม่ปลด guard

1. **เตียง**: `h=600` ใน spec คือความสูง *ก้อนมวลที่เขียนในแบบ* ไม่ใช่เตียงที่มีหัวเตียง ของจริง
   มีหัวเตียงสูง 1000–1400 · จะแก้ต้องประกาศ envelope สำหรับ "ตอนซื้อ" แยกจาก h ที่มาจากแบบ
   (แก้ h ในแบบเพื่อให้โมเดลผ่าน = แก้แบบให้เข้ากับของ ซึ่ง R12 ห้ามตรง ๆ)
2. **ม้านั่ง**: slot ยาวตามแกน y แต่ม้านั่งจริงทุกตัว export ยาวตามแกน x · **และข้างหลังนั้นมี
   ความไม่ตรงกันที่ซ่อนอยู่จริง** — `place_model` fit เข้า (w,d) *แล้วค่อยหมุน* แต่ spec ชุดนี้เก็บ
   w/d เป็น footprint ของ *โลก* แล้ว การหมุน cardinal จึงจะทำให้ผังเลื่อน ทุกเคสที่ผ่านมารอด
   เพราะเป็นของเกือบจัตุรัส (สตูล 510×546) จึงไม่มีใครเห็น
3. **พรม**: อัตราส่วนที่เขียนในแบบคือ 1.24 ของที่โหลดมาได้ 0.68/1.17/1.50 — **ต้องหาใบที่สัดส่วน
   ตรง ไม่ใช่ยืดใบที่ผิด** (การยืดแบบไม่เท่ากันคือการโกหกเรื่องสัดส่วนสินค้าจริง ซึ่งเป็นจุดขายของเราเอง)
