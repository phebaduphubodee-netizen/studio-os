## 6. รอบนี้เจอข้อบกพร่องใน **เครื่องมือของเราเอง** และเจอด้วย positive control

`p2_exit.wood_boards` รายงาน "no peak above floor" มา 5 รอบติด ก่อนจะเชื่อว่านั่นคือ "ไม่มีข้อบกพร่อง" รอบนี้รัน control ตามกฎของ R11 (*"ข้อความว่าไม่มี ต้องมี positive control เสมอ"*):

```
crop width 720 -> search bound hi = W//2 = 360
  2x tile (repeat lag 360px): peak 0.000  -> MISSED
  3x tile (lag 240px):        peak 1.000  -> DETECTED
  4x tile (lag 180px):        peak 1.000  -> DETECTED
  5x tile (lag 144px):        peak 0.999  -> DETECTED
```

`autocorr_peak` วน `for m in range(max(min_lag,1), hi-1)` โดย `hi = W//2` — **การซ้ำแบบ 2 แผ่นอยู่ที่ lag = W/2 พอดี ซึ่งอยู่นอกลูป**

docstring ของ rung เขียนเองว่ามีไว้จับ *"Two adjacent boards carrying the same cathedral figure"* — **และ "สอง" คือกรณีเดียวที่มันมองไม่เห็น** crop ที่ประกาศไว้ก็กว้างสองแผ่นพอดี วิธีวัดกับ crop จึงขัดกันเอง

วัดใหม่ที่ crop กว้างพอให้ control ทำงาน (1056 px, lag ถึง 526, พิตช์แผ่นจริง ~300-370 px): **peak 0.085 vs floor 0.335 → ไม่มีการซ้ำเชิงคาบ**

**แต่ยังหักล้าง C3#6/C2#17 ไม่ได้** เพราะ autocorrelation ตอบเรื่อง *คาบ* ส่วนตาสองคู่พูดถึง *ความคล้ายของลาย* ซึ่ง texture เดียวกันคนละ offset ก็ให้ผลแบบนั้นได้โดยไม่มีคาบ **ยอมรับตรง ๆ ว่าเครื่องมือยังตอบคำถามที่ตาถามไม่ได้ ดีกว่าเอาเลขที่วัดคนละเรื่องมาปิดปากกรรมการ**
