## The design move — why ONE collection, and why Purist
A master ensuite's brass is jewelry: mixers, tub filler, handshower, shower control, towel bar, hook,
paper holder all sit in one small room in one finish. If each comes from a different Kohler line the
*finish* matches but the *forms* don't — spouts, levers, escutcheons, knurling all disagree. The
high-design move is a **single collection** so every silhouette is drawn from one language.

**Purist wins on completeness.** Of the three modern minimalist Kohler lines in `-2MB`:
- **Purist — 8/8.** The only one that natively covers the whole set *including the shower* (its own
  handshower-on-slidebar kit **and** a thermostatic trim) plus a full accessory family. Architectural,
  slim cylindrical, near-zero ornament; in satin `-2MB` it reads as a soft warm metal against warm oak
  + cool porcelain + frameless glass. Every one of its 8 SKUs was independently re-verified in `-2MB`.
- *Composed (6/8)* — the softest, most "jewelry" minimalist (a hair more refined than Purist on the
  lav/accessory side) **but no shower gear and no thermostatic** at all → the entire shower would be
  borrowed. Runner-up if you prefer the most understated lav look and accept an all-neutral shower.
- *Components (6/8)* — industrial-precise, native thermostatic + deck filler + accessories, but a
  build-your-own kit (more parts) and no shower head/hand either.

Purist needs only **two genuinely neutral** pieces borrowed — a rain **disc** and a thermostatic
**control plate** — both of which read as neutral by nature, not as "a second collection." So the
single-collection read stays intact.

## Shower architecture (so it plumbs correctly)
One **Anthem 2-outlet thermostatic** control (#7) feeds **outlet 1 → the ceiling rain disc** (#8) and
**outlet 2 → the Purist handshower on its slidebar** (#2). Temperature is set once (thermostatic); the
panel's two buttons select/run each outlet. The **tub deck filler** (#3) is a *separate* self-contained
3-hole deck set with its own handles + rough-in valve — independent of the shower. This matches the ink
(rain + handheld in the wet zone; deck filler on the tub deck).

## Genuine spec residuals (design/M&E — **not** price)
1. **Basin mounting + rim height.** Purist Tall (#1) is a tall gooseneck for vessel/countertop basins —
   confirm the basins are vessel (DD §2/§7) and that the spout height clears the rim with usable
   stream-to-basin drop. If undermount, the Purist standard single-hole is the swap.
2. **Ceiling rain vs the RCP.** #8 is ceiling-fed → the RCP must run an in-ceiling supply drop in the
   §11.8 service bulkhead (the bulkhead is already planned, so this is likely fine). If ceiling can't be
   fed, Purist has a wall arm (K-933-2MB) for a wall-fed disc.
3. **Rough-in valve bodies** (all trim-only, as premium valves are): Anthem body **K-39013** (#7);
   a **high-flow** rough-in for the tub filler (#3); the MasterShower/rough behind the handshower feed.
   The plumber sizes/orders these with the trims.
4. **Cuff `-B-2MB` hose+bracket kit** (#9) — confirm with the dealer.
5. **Finish-batch consistency (quality point).** Brushed/PVD brass can vary *slightly* batch to batch.
   Order the **entire suite in one PO / one batch from one supplier** so every piece is the same run —
   the single biggest lever on whether the brass actually reads as one finish in the room.
