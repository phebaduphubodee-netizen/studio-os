# Checklist by Stage

> Gate criteria สำหรับแต่ละ stage — ต้อง check ครบก่อนข้ามไป stage ถัดไป
> Claude Code ใช้ไฟล์นี้เช็คว่า project พร้อมขยับไปไหนได้แล้ว

---

## Stage 1 — Brief

ต้องมีก่อนจะเริ่มออกแบบ:

- [ ] รายชื่อสมาชิกที่อยู่อาศัย (อายุ, lifestyle)
- [ ] Budget range (top / target / floor)
- [ ] Timeline ที่ต้องการเสร็จ
- [ ] Reference images อย่างน้อย 5 ภาพ (ดี + ไม่ชอบ)
- [ ] ขนาด + ผังพื้นที่จริง
- [ ] Must-have features (list)
- [ ] Deal-breakers (list)
- [ ] สัญญา / contract signed
- [ ] เงินมัดจำเข้า (50% design fee)

**Gate check**: ถ้าครบ 7/9 → proceed. ถ้าน้อยกว่า → กลับไป brief เพิ่ม

---

## Stage 2 — Mood & Zoning

- [ ] Mood board ส่ง 2-3 options
- [ ] Zoning plan 2-3 options พร้อมเหตุผล
- [ ] ลูกค้าเลือก mood + zoning แล้ว
- [ ] Written approval (เป็น email หรือ LINE ก็ได้)
- [ ] Budget allocation breakdown ต่อ zone

**Gate check**: ลูกค้า sign-off เป็นลายลักษณ์อักษร

---

## Stage 3 — 3D Design

- [ ] 3D model ครบทุก zone หลัก
- [ ] วัสดุปิดผิวกำหนดครบ (ที่ตำแหน่งหลัก ๆ)
- [ ] เฟอร์นิเจอร์ลอยตัววางแล้ว
- [ ] Lighting plan layer ครบ (ambient + task + accent)
- [ ] Review ภายในสตูดิโอเสร็จ

**Gate check**: ตัว design ภายในสตูดิโอเห็นพ้องว่า "ส่งได้"

---

## Stage 4 — Render & Presentation

- [ ] Render มุมหลักครบ (LR, DR, MBR, kitchen min)
- [ ] Material schedule ระบุชัดเจน
- [ ] Furniture list พร้อม source + price
- [ ] Presentation deck เตรียมแล้ว
- [ ] นัด present ลูกค้าแล้ว

**Gate check**: present เสร็จ + ลูกค้า approve

---

## Stage 5 — Material & Furniture Confirmation

- [ ] Material samples นำเสนอลูกค้าแล้ว
- [ ] ลูกค้าเลือก final material ครบทุกตำแหน่ง
- [ ] Furniture confirm รายตัว + supplier confirm stock
- [ ] Lead time supplier เก็บข้อมูลแล้ว
- [ ] Deposit furniture / built-in suppliers จ่ายแล้ว

**Gate check**: Material schedule final + supplier confirmation

---

## Stage 6 — Construction Drawing

- [ ] Floor plan (furniture + dimension)
- [ ] Demolition plan
- [ ] Ceiling plan (lighting + AC)
- [ ] Floor pattern + material
- [ ] Wall elevation ทุก wall ที่มี built-in
- [ ] Section drawing ที่จำเป็น
- [ ] Detail drawing (built-in, joinery)
- [ ] Electrical plan
- [ ] Plumbing plan (ถ้ามี modification)
- [ ] AC drawing
- [ ] Door + window schedule
- [ ] Material schedule
- [ ] BOQ final

**Gate check**: drawing set ครบ + checked by senior

---

## Stage 7 — Construction

ต้องเตรียมก่อนเริ่มก่อสร้าง:

- [ ] Contractor selected + signed
- [ ] BOQ approved by client
- [ ] Drawing set ส่งให้ช่างหมดแล้ว
- [ ] Site brief meeting ทำแล้ว
- [ ] Permit จากนิติบุคคล (ถ้าคอนโด)
- [ ] เงิน construction milestone 1 เข้าแล้ว

**During construction** (recurring):
- [ ] Site visit อย่างน้อย 1x/สัปดาห์
- [ ] Site report ทุก visit (`08-site-reports/`)
- [ ] Photo documentation
- [ ] Variation order (VO) ถ้ามีการเปลี่ยนแปลง
- [ ] Material delivery ตรงตาม spec

---

## Stage 8 — Inspection & Punch List

- [ ] Pre-handover inspection โดยทีม design
- [ ] Punch list สร้างจาก site photos
- [ ] ส่ง punch list ให้ contractor
- [ ] Re-inspect after fix
- [ ] Client walk-through
- [ ] Client punch list (ของลูกค้าเอง)
- [ ] Final fix

**Gate check**: punch list 100% close

---

## Stage 9 — Handover

- [ ] House manual (วัสดุ + วิธีดูแล)
- [ ] Warranty documents รวบรวม
- [ ] Supplier contact list
- [ ] Spare materials handed over
- [ ] Photo handover (พร้อม before/after)
- [ ] Final invoice
- [ ] Client sign-off form
- [ ] เงินงวดสุดท้ายเข้า

**After handover**:
- [ ] Project moved to `90-Archive/`
- [ ] Testimonial requested
- [ ] Portfolio photoshoot (if applicable)
- [ ] Internal post-mortem ทำเสร็จ

---

*ปรับ checklist ตามจริงของสตูดิโอ — ยิ่งตรงยิ่งดี*
