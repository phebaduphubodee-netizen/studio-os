# Materials Database

> Library ของวัสดุที่ใช้บ่อย — copy `[[20-Templates/material-card-template]]` มาเป็น card ใหม่
> ตั้งชื่อไฟล์: `category-brand-model.md` (kebab-case)

## Organize by category

แนะนำตั้ง subfolder:
- `floor/`
- `wall/`
- `ceiling/`
- `counter/`
- `fabric/`
- `lighting/`
- `hardware/`
- `sanitary/`

## Quick browse

ใช้ Obsidian's tag pane: `#material` แล้วกรองตาม category

## Sync with projects

ทุกครั้งที่เลือก material ใน project ใหม่ — ลิงก์กลับมา card นี้ด้วย:
```markdown
ใน project file: [[30-Materials-DB/floor/oak-engineered-12mm]]
ใน material card: ใส่ใน "Used in projects": [[10-Clients/...]]
```
