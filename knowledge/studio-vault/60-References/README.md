# References

> Inspiration images, case studies, building codes, articles

## Suggested structure

- `inspiration/` — ภาพ reference จาก Pinterest, Instagram, Behance
- `case-studies/` — งานเสร็จที่ดี (ของเราหรือคนอื่น)
- `codes/` — Building code, นิติบุคคล rules
- `articles/` — บทความ trend, technique

## Naming

- Images: `keyword-source.ext` (e.g. `japandi-livingroom-pinterest-001.jpg`)
- Notes: `topic-description.md`
