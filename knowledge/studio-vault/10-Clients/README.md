# Clients

> One subfolder per project. Use `/new-project` in Claude Code to scaffold from `_TEMPLATE/`.

## Folder naming

`YYYY-FirstName-PropertyType-Location`

Examples:
- `2026-Khun-Aom-Condo-Sukhumvit`
- `2026-Khun-Earth-House-Bangna`
- `2026-Khun-Mint-Townhome-Ratchada`

## Active vs archive

- **Active** = here
- **Archived** = `90-Archive/`

Move folder when project complete + invoice paid + post-mortem done.
