# Templates

> Reusable templates for vault items outside of projects

## Available templates

- [[material-card-template]] — for new material entries in `30-Materials-DB/`
- [[supplier-card-template]] — for new supplier in `40-Suppliers/`
- [[contractor-card-template]] — for new contractor in `50-Contractors/`

## How to use

1. Copy template
2. Rename to descriptive kebab-case filename
3. Fill in fields (leave blank if unknown — better than guessing)
4. Save in correct folder
5. Tag appropriately
