# Archive

> Completed / cancelled projects ย้ายมาที่นี่

## When to archive

- [ ] Project officially handed over
- [ ] Final payment received
- [ ] Defect period ended (or transferred to separate tracking)
- [ ] Internal post-mortem done

## How to archive

1. Move project folder from `10-Clients/` to here
2. Update `00-project-overview.md` status to `archived`
3. Update any [[wikilinks]] that may break
4. Tag with `#archived` and `#year/YYYY`

## Naming after archive

Keep original name, optionally append outcome:
- `2025-Khun-A-Condo` (default)
- `2025-Khun-A-Condo-cancelled` (if cancelled)
- `2025-Khun-A-Condo-portfolio` (if showcase-worthy)
