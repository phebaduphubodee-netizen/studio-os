User wants material recommendations for active project.

## Steps

1. **Identify project** and zone (LR, MBR, kitchen, bath, etc.)

2. **Load context**:
   - `02-mood-and-tone.md` — style direction + palette
   - `01-brief.md` — budget tier (budget / mid / premium)
   - `05-furniture-and-materials.md` — what's already selected

3. **Search**:
   - First: `30-Materials-DB/` for matching cards in vault
   - Then: web search for current options if vault lacks

4. **Recommend** 3-5 options per surface, in table:

   | Option | Spec | Price/sqm | Supplier | Match to mood | Pros / Cons |
   |--------|------|-----------|----------|---------------|-------------|

5. **Recommend top 1-2** with confidence note

6. **Offer to add** to `30-Materials-DB/` if not yet a card

## Style

- Cite suppliers from `[[40-Suppliers]]` first
- Flag new suppliers as `[NEW SUPPLIER]`
- Match to specific words from mood document
