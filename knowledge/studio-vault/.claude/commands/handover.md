description: Assemble handover package for a project
---

User is preparing to handover a completed project.

## Steps

1. **Verify project is ready**:
   - Check `09-punch-list.md` → 100% verified?
   - Check `06-boq.md` → final invoice prepared?
   - All site reports closed?

2. **Read** across project:
   - `05-furniture-and-materials.md` → all materials + suppliers
   - All site reports → final state
   - `04-decisions.md` → key decisions for client reference

3. **Generate** `10-handover.md` package:
   - House manual (material care guide per surface)
   - Maintenance schedule
   - Supplier contact consolidated list
   - Warranty list with dates
   - Spare materials inventory

4. **Create handover PDF-ready markdown** for client

5. **Generate post-handover task list**:
   - Photoshoot schedule
   - Testimonial request
   - Archive prep
   - Internal post-mortem

## Style

Client-facing tone in handover doc — friendly, clear, no jargon.
Internal tasks separate at bottom.
