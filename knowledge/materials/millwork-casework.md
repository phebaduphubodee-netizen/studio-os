## 1. ขอบเขตงาน: Division 06 กับ Division 12 / Scope split — built-in vs manufactured

The technical language of high-customization residential work revolves around
three terms: **architectural woodwork, millwork, casework** (Interior Design
Knowledge Structuring.pdf p.5). Specification must differentiate two divisions
within standard construction classifications (p.5):

| Division | ขอบเขต / Scope | Governance |
|---|---|---|
| **Division 06** — Wood, Plastics, and Composites | Custom, **site-specific fabrication** — architectural woodwork / งานบิวท์อินสั่งทำเฉพาะหน้างาน | Architectural Woodwork Institute (**AWI**) standards (p.5) |
| **Division 12** — Furnishings | Furnishings (p.5 names only "Furnishings"; the manufactured/freestanding เฟอร์นิเจอร์ลอยตัว-ผลิตสำเร็จ gloss is inferred from the contrast with Div 06's "custom, site-specific fabrication"*) | — (source names no governing body) |

Practical rule for the studio: a wardrobe built into the wall of a Thai condo
is Division 06 scope (AWI vocabulary applies); a purchased freestanding
wardrobe is Division 12 scope (FF&E lane — see `ffe-research` outputs).

- p.5 calls these "standard construction classifications" without naming the
  system, but the corpus itself names it elsewhere: CSI **MasterFormat**
  (50 divisions, Work Results) at Interior Design Knowledge Structuring.pdf
  p.9 — no `*` needed.
- The Division taxonomy (MasterFormat / UniFormat / OmniClass) is covered in
  `knowledge/classifications/design-domain-taxonomies.md` — that file owns
  classification-system scope; this file only carries the Div 06 vs Div 12
  practical split for millwork specification.

## 2. การผ่าวีเนียร์ / Veneer cuts

Source names four cuts as the specification variables (Interior Design
Knowledge Structuring.pdf p.5): **rotary, plain sliced, quarter sliced, rift
cut** — chosen because they dictate "material performance and aesthetic
sequencing" (p.5).

| Cut / วิธีผ่า | ลายที่ได้ / Typical appearance* |
|---|---|
| Rotary ปอกหมุนรอบซุง | broad, variegated "wild" grain; widest sheets, most economical* |
| Plain sliced (flat cut) ผ่าเรียบ | cathedral / crown grain ลายภูเขา* |
| Quarter sliced ผ่าเสี้ยว | straight, tight vertical stripe ลายเส้นตรง* |
| Rift cut ผ่าริฟท์ | straightest grain, minimizes ray flake (esp. oak)* |

- GAP: the corpus names the four cuts but describes **no** appearance or
  yield differences — the appearance column above is unverified general
  reference (*); re-source before it enters drawings or a client spec.

## 3. การเรียงลายวีเนียร์ / Veneer matching

Two matching techniques named (Interior Design Knowledge Structuring.pdf p.5):

- **Book matching** เรียงลายกระจกเงา — adjacent leaves opened like a book;
  mirror-image grain at each seam.*
- **Slip matching** เรียงลายเลื่อน — leaves slid in sequence, same face up;
  repeating (not mirrored) grain, avoids the barber-pole light/dark
  alternation of book matching.*

- GAP: source names the two techniques only; the appearance descriptions are
  general reference (*). Other matches (random, end, balance matching) are not
  in the corpus — do not cite them from this file.

## 4. วิธีเข้าไม้ / Joinery methods

Structural parameters are defined by joinery method (Interior Design Knowledge
Structuring.pdf p.5): **dovetail** เดือยหางเหยี่ยว, **mortise and tenon**
เดือยและรูเดือย (การเข้าเดือย), **biscuit joints** เดือยบิสกิต.

- AWI-grade specification cross-references the required grade **against the
  specified joinery and substrate types** to keep structural integrity and
  aesthetic cohesion across bespoke elements (p.6) — i.e. joinery choice is a
  grade-compliance variable, not a style preference.
- GAP: the corpus ranks no joint over another and gives no load or drawer-box
  guidance (e.g. "dovetail for drawers" is convention*, not corpus).

## 5. การปิดขอบ / Edge banding on panel substrates

Specification defines "the precise application of **hardwood or 3 mm PVC edge
banding** to **plywood or particleboard** substrates" (Interior Design
Knowledge Structuring.pdf p.5).

| Edge / วัสดุปิดขอบ | Substrate ที่ระบุในแหล่ง | Note |
|---|---|---|
| Hardwood ไม้จริง | plywood ไม้อัด, particleboard | source pairs both substrates with either edge type (p.5) |
| PVC 3 mm ขอบพีวีซี | plywood, particleboard | 3 mm is the only numeric the corpus gives in this domain |

- GAP: no thinner PVC gauges (0.4–2 mm*), no ABS/acrylic edging, and no
  adhesive systems (EVA/PUR*) appear in the corpus.

## 6. เกรดคุณภาพ AWI / AWI quality grades

For luxury-residential construction documents, the AI/specifier
cross-references the required **AWI Custom or Premium grades** against joinery
and substrate types (Interior Design Knowledge Structuring.pdf p.6).

- Only **Custom** and **Premium** are named in the corpus. AWI's full grade
  ladder (incl. Economy*) is not in the source — GAP: do not cite a third
  grade from this file.
- Studio default expectation: state the target AWI grade in the millwork spec
  so joinery + substrate choices can be audited against it (p.6 pattern).

## 7. พฤติกรรมวัสดุในเขตร้อนชื้น / Tropical substrate behavior — cross-ref only

Humidity behavior of the substrates above is governed by
`knowledge/materials/residential-materials.md` — cite that file, do not
restate values here:

- Particleboard: swells irreversibly when moisture enters seams/edges — see
  the **countertop** laminate row of `residential-materials.md` (particleboard
  substrate, [t3-1]); the flooring laminate row describes a fiberboard core
  and is `*`-tier there. Direct consequence here: edge banding integrity
  (ข้อ 5) is the moisture seal on Thai-climate particleboard casework.
- Solid wood / wood paneling: dimensional movement under humidity swings —
  see `residential-materials.md` [t3-1] rows. Consequence: joinery and veneer
  layup must tolerate movement; quarter/rift material is conventionally more
  stable than plain sliced* (not corpus-grounded).
