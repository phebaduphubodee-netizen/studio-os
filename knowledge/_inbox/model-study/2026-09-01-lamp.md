## idiom ที่พบ (ตัวเลข)

1. **ไม่มีสายไฟ 0/4 — แต่มีกลไกสวิตช์** — grep `cord|cable|wire|plug` ทั้ง 7 dump = 0 ชิ้น ทุก tier
   สิ่งที่ pro ใส่แทนคือฮาร์ดแวร์ที่ตามองหา: pull-chain (01bb0e45 `chain`, ø3.2×140 mm, 6,110 verts,
   verts_per_m2 3.9 ล้าน), harp+rings, หลอด+ขั้ว (`Bulb` 44.9×52.8 mm + `white bulb bracket` 47.5 mm),
   ปุ่มไขลานนาฬิกา, สกรู 3.2 mm. สาย/ปลั๊กถูกทิ้ง (โลกจริงมันซ่อนหลังเฟอร์นิเจอร์เสมอ)
2. **emitter มี 3 สูตร ไม่เคยเป็น "shade เรืองแสง"** —
   (a) Point/LIGHT object ในตัว asset: 01bb0e45 `Light`, dcebfd80 `Point.007` (2/4)
   (b) ไส้หลอด mesh เปล่งแสง: MWAFillament Emission 2500 + BLACKBODY (1/4) — และกระจกหลอด mix
   GLASS/TRANSPARENT ด้วย LIGHT_PATH node (dump บอกแค่มี node ไม่บอก socket — สูตรมาตรฐานคือปล่อย
   shadow ray ผ่าน แต่ต้องเปิด .blend ยืนยัน), solidify 2 mm
   (c) ไม่มีไฟเลย = โคมประดับ (Kendra)
3. **shade = ผนังเดี่ยว + SOLIDIFY 1 mm + Transmission** — cage 160–256 quads เท่านั้น;
   ผ้า linen Transmission Weight 0.333 (ทั้งสองโคม free ใช้ material ชุดเดียวกัน), กระดาษใช้ Subsurface Weight 1.0;
   แสงจึง "ติดใน shade" ได้แบบหรี่ ไม่ใช่ทะลุหมดหรือทึบหมด
4. **ฐานโค้ง = cage เล็ก + SUBSURF viewport 1 / render 2 + ตัวเก็บขอบ** — โดมหิน 262 mm ใช้ 770 verts
   (2,545 v/m²), ฐานไม้ 239 mm ใช้ 608 verts, ฐาน MWA 512 verts; ฐานไม้ทั้งสอง smooth_share 0.0 +
   WEIGHTED_NORMAL (flat-shade แล้วให้ WN เก็บขอบ) แต่โดมหิน smooth 1.0 + NODES "Auto Smooth" (ไม่มี WN)
   — ตรงกับ stats subsurf_share 0.9 ของคลาส
5. **นาฬิกา = ชิ้นกลไกแยกชิ้นระดับมิลลิเมตร ตั้งฉากเวลาเป็นจริง หน้าเอียงหลัง ~6.7°** —
   เข็ม 5 ชิ้น (รวม hub และเข็มวินาที) หนา 0.8–1 mm (hub 2.4) หมุนไปที่เวลาใดเวลาหนึ่งจริง; หน้าปัด = ภาพ 1024–1600 px
   ไม่ปั้นตัวเลข; ตัวเรือนเอียง 83.2° / 96.65° (สองเจ้าอิสระต่างเลือก 90±6.7° เหมือนกัน = ตั้งใจให้อ่านจากมุมยืน)
6. **ความหนาแน่นตามความโค้ง ไม่ใช่ตามความสำคัญ** — shade 976–1,752 v/m² · โดมหิน 2,545 · ฐานไม้ 3,415–4,229 ·
   โซ่ 3.9M · สกรู 3.2 mm = 6.6M v/m²; ทั้งโคมจบใน 800–9,210 verts
7. **วัสดุตั้งชื่อตามสสารและ reuse ข้ามชิ้น** — `metall` users 7, `clock-body` users 7, `材质.003` users 11;
   โลหะไม่มี texture ก็สวยด้วย procedural: NORMALMAP<VALTORGB<PROC:NOISE>> mapping_scale 30 (โคม full_plan
   9,210 verts ใช้ภาพ **ศูนย์แผ่น**)

## กฎ transferable จัดอันดับ

1. **นโยบายเงาเป็นของ material ไม่ใช่ของ object** — แก้ `visible_shadow=False` เหมารวม (build_room.py:12701)
   เป็น: ฐานทิ้งเงาเต็ม · shade ได้ Transmission ~0.33 (มีอยู่แล้วใน material ที่ import มา!) · เฉพาะ
   หลอด/กระจกถ้ามีค่อยใช้ LIGHT_PATH mix. พิสูจน์ด้วยพิกเซล contact shadow ใต้ฐานโคม
2. **อย่าโมเดลสายไฟ — โมเดลสวิตช์** — pro 0/4 มีสาย แต่ full_plan ใส่ pull-chain+harp+หลอด 10 ชิ้น;
   sense-list ของเราต้องเล็งใหม่จาก "ไม่มีสายไฟ" (ซึ่ง pro ก็ไม่มี) ไปที่ "ไม่มีกลไกเปิด-ปิด/ฮาร์ดแวร์แขวน"
3. **โคมมีไฟจริงต้องมี "หลอด" เป็นวัตถุ** — จุด LIGHT ลอยกลาง shade เฉย ๆ คือครึ่งเดียวของ idiom;
   อีกครึ่งคือ mesh หลอด Transmission 1.0 (หรือไส้ emissive + BLACKBODY) ให้ตาเห็นแหล่งกำเนิด
4. **ผิวโค้งของตกแต่ง = cage 500–800 verts + SUBSURF 1/2 + ตัวเก็บขอบ (WEIGHTED_NORMAL หรือ Auto Smooth)** ไม่ใช่ lathe หนา
   และไม่ใช่ mesh อบ level 1 — path GLB ของเราตัด density render ลง 4× และทิ้ง displacement โดยไม่มีใครเห็น
5. **เปลือกบาง = ผนังเดี่ยว + SOLIDIFY (1–2 mm)** — shade 160 quads, กระจกหลอด 128 quads;
   อย่าปั้นสองชั้นเอง อย่าปล่อยแผ่นเดียวไร้ความหนา
6. **ของมีหน้าปัด: หน้า = image texture, กลไก = ชิ้นแยก mm-scale, ตั้งฉากใช้งานจริง** — เข็มตั้งเวลา,
   หน้าเอียง ~6.7°, ปุ่ม/สกรู 3.2–15.4 mm; หรือถ้าซื้อ: mesh เดียว + Opacity map ก็เป็นสูตรที่ตลาดยอมรับ
7. **โลหะไม่ง้อ texture** — Principled Metallic 1.0 + Roughness 0.10–0.23 + normal จาก
   NORMALMAP<VALTORGB<PROC:NOISE>> mapping_scale ~30 (ทำใน material_presets ได้เลย ศูนย์ไฟล์ภาพ)
8. **งบ verts จ่ายตามความโค้ง** — ทั้งโคม ≤ ~9k verts แต่โซ่/สกรูกิน 3.9–6.6M v/m² ได้;
   อย่าเกลี่ย density เท่ากันทั้ง asset

## คำถามที่ต้องพิสูจน์ด้วยพิกเซล

1. เปิดเงาฐานโคมกลับ (เลิก visible_shadow=False เฉพาะ base) — contact shadow ใต้โคมทำให้เฟรมดีขึ้น
   หรือดักแสง practical จนโต๊ะมืด? (ต้อง A/B ที่ p2r-next)
2. shade Transmission 0.333 + แสงในโคม เรนเดอร์แล้วเห็น "glow gradient" บนผิว shade จริงไหม
   เมื่อ mesh เราถูกอบและไม่มี solidify ชั้นในเหมือนต้นฉบับ?
3. mesh อบ level 1 (2,370 verts) vs เจตนา vendor level 2 — silhouette ของ shade 298 mm มองเห็น faceting
   ที่ระยะกล้อง p2r91 หรือไม่? (ถ้าเห็น → import จาก .orig.blend หรือ re-subdivide)
4. emitter ที่ 0.62 ของความสูงโคม (304 mm บน Kendra 490 mm — sidecar bbox z 490, ไม่ใช่ 594) อยู่ต่ำกว่า
   กึ่งกลาง shade ~81 mm และเหนือขอบล่าง shade เพียง ~23 mm (shade กิน 280.5–489.5 mm จาก loc/dims ใน dump)
   — ต่ำขนาดนี้เห็นจุดสว่างเปลือยจากมุมกล้องเตียงหรือไม่? (dump บอกตำแหน่ง ไม่บอกว่าตาเห็นอะไร)
5. DISPLACEMENT 0.01 ของ linen ที่หายไปตอน GLB — บนโคมไกลกล้องมีผลมองเห็นจริงหรือเป็นของฟรีที่ไม่ต้องทวง?
6. เข็มนาฬิกา 1 mm / สกรู 3.2 mm ที่ระยะ nightstand-to-camera ของเรา เกิน 24 px ไหม (เกณฑ์ sub-24px
   ของ P2r-33) — ถ้าไม่ถึง การซื้อแบบอบรวม (ed37bde3) คือคำตอบที่ถูกกว่า
