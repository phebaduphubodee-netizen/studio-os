## 3. กฎ transferable — เขียนเป็น testable

**R1 — เบาะบุนวมอยู่ที่ 55,834–471,211 v/m²; ต่ำกว่า 25,000 คือของที่ pro ใช้ทำโครง ไม่ใช่เบาะ.**
วัดในเฟรม: `v_per_m2` ของทุก mesh ที่สวมวัสดุ `acq_*_uph` / `acq_bench_seat` — ตัวกรองนี้เลือกได้ **4 ชิ้น** และวันนี้อ่านได้ **626–4,677 = shell ทั้งหมด**. **หักล้างได้ถ้า** ที่ระยะกล้อง p2r91 ของนั่งกินพื้นที่ต่ำกว่าเส้น 24 px (p2r87b) จนความหนาแน่นไม่มีผล — วัดด้วย `id_mask.py` บน mask ของ bench/stool

**R2 — ตะเข็บของเบาะ pro เป็น OBJECT แยกที่มีวัสดุของตัวเอง หนาแน่นกว่าเบาะในตัวเดียวกัน 5.5–315× (3/6 ตัว).**
วัดในเฟรม: นับ mesh ที่ ≥1,000,000 v/m² ในกลุ่มของนั่ง — วันนี้ **0**. **หักล้างได้ถ้า** การดึงที่นั่งครั้งถัดไป (≥6 ตัว) พบว่าเกินครึ่งไม่มีชิ้น detail เลย → แปลว่า 3/6 เป็นความบังเอิญของกลุ่มตัวอย่างนี้

**R3 — จำนวน mesh ต่อเก้าอี้ 1–11 (median 5); เก้าอี้ที่เป็นเมชเดียวมีจริง (ottoman 10542494) แต่มันชดเชยด้วยความหนาแน่น 195,128 v/m².**
เป็น **negative test**: กันไม่ให้สรุปว่า "ต้องแยกหลายชิ้น" — สิ่งที่ต้องมีคือความหนาแน่น ไม่ใช่จำนวนชิ้น. **หักล้างได้ถ้า** พบเก้าอี้เมชเดียวที่ < 55,834 v/m² แล้วยังผ่านสายตา

## 4. คำถามที่ต้องพิสูจน์ด้วยพิกเซล

1. ตะเข็บ 0.2 mm ที่ระยะกล้อง p2r91 กินกี่พิกเซล — ถ้าต่ำกว่า 1 px มันไม่ใช่เรขาคณิตที่ต้องมี แต่เป็นเรื่องของ normal map และ R2 ต้องเปลี่ยนรูป
2. `stool__acq2` ที่ 626 v/m² (edge 39.8 mm) อยู่ในเฟรมหรือถูกครอบตัด — ถ้าอยู่ มันคือชิ้นที่หยาบที่สุดของหมวดนี้ในภาพ
3. ของนั่งของเราอ่านเป็น "บุนวม" หรืออ่านเป็น "กล่องหุ้มผ้า" ที่ระยะเตียง — ข้อนี้ตาตัดสิน ไม่ใช่ความหนาแน่น

## 5. ที่ไม่ได้ดึงและเหตุผล

คำค้น armchair / lounge chair / ottoman / accent chair / upholstered chair → **916 ตัวไม่ซ้ำ** · กรองด้วยแบนด์ `chair` ของ asset_scale (z 0.60–1.30 m) + faces ≥ 500 เหลือ **631** · แล้วตัด**ชุด** (sofa set / patio set / dining set) ออกด้วยเงื่อนไขว่าทั้งสองแกนในระนาบ ≤ 1.20 m เหลือ **504 ตัวที่เป็นที่นั่งเดี่ยว** (full_plan 386 / free 118) · เลือก **5 ตัวจากกลุ่ม 504 นี้**: ตัวหนาแน่นสุดฝั่งเสียเงิน (a34e3cdf 3.19 M faces), ฝั่งฟรี 62520f38 ที่ **1.07 M ซึ่งเป็นอันดับสอง ไม่ใช่ที่หนึ่ง** (ที่หนึ่งคือ 6c4752d5 Leather lounge chair 1.31 M — ผมเขียนผิดว่ามันคือตัวสุดขั้ว และไม่ได้ดึงตัวนั้นมา), ผ้าลินินแทนหนัง, ตัวที่ส่ง `Sewing` มา, และเก้าอี้โครง+เบาะแบบคลาสสิก · **ตัวที่ 6 คือ ottoman 10542494 ซึ่งไม่ได้มาจากกลุ่ม 504**: ระนาบของมันคือ 1978×922 mm จึงตกเงื่อนไข ≤1.20 m ทั้งสองแกน — ดึงมาจากกลุ่ม 631 เป็นข้อยกเว้นเชิงคลาสโดยตั้งใจ · ที่ตัดออกทั้งกลุ่ม: ชุดกลางแจ้ง/หวายซึ่งครองอันดับต้นของ faceCount แต่เป็นหลายชิ้นในหนึ่ง asset จึงเทียบความหนาแน่นต่อชิ้นไม่ได้
