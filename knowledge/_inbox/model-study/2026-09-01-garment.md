## idiom ที่พบ (ตัวเลข)

1. **ไม้แขวนเป็น MESH 100% — CURVE = 0 ใน 12 asset** (stats: curves max 0 ทั้ง garment_hung และ hanger). ตัวไม้หนา 16.5mm (03ede500 wood hanger dims 16.5×411.9×149.4) หรือ 38.1mm (ce055de1), hook โลหะเป็น mesh แยก 760 verts (03ede500) หรือหลอมใน mesh เดียวแล้วแยกด้วย material slot (ce055de1: hangerWood+hook)
2. **เสื้อมีสองตระกูลการสร้าง**: (a) quad cage 1,550–2,250 v/m² + SUBSURF render_levels=2 (view 1–2: shirt/dress view 1, jacket และ wood hanger view 2) — ตระกูล cloth-deco ทั้ง 3 + maxi; cloth-deco 3 ตัว tris=0 + vertex_groups=1 (= pin group ของ cloth sim) แต่ maxi มี tris=4 และ vg=0 (ไม่มี pin group); (b) mesh อบสำเร็จ ไม่มี modifier เลย 1,875–3,303 v/m² (polo/vneck 6 ตัว). ไม่มีตัวไหนเกิน **5,422 verts ต่อทั้ง asset**
3. **ความหนาผ้า**: มีที่เดียวที่ประกาศ = maxi dress SOLIDIFY thickness 0.0025m offset −1; ที่เหลือผิวเดียว — ตระกูล baked (polo/vneck/maxi) ใช้ normal map 4096 แบก hem/collar/สาบ, ตระกูล procedural ใช้ BUMP จาก noise (ไม่มี normal map เลย) (ใน dump ไม่มี geometry ขอบแยก; ร่องรอยที่พอนับได้: polo มี 272 tris + smooth_share 0.864 = มีหน้า flat ~13.6% น่าจะกระดุม/ขอบแข็ง)
4. **สูตร Procedural Fabric** (4/18 material = 22.2% — ไม่ใช่ตัวเดียวที่ทำให้ procedural-only 44.4%: ค่านั้นคือ 8/18 รวม hook ×3 ที่เป็น proc-noise และ maxiDress ที่ node_hist เห็นแค่ GROUP ทั้งที่ใช้รูป 5 ใบข้างใน group): `TEX_NOISE×2 + TEX_WAVE×1 + TEX_VORONOI×2 → MIX×9 → VALTORGB×3` แตกเข้า 4 ช่อง: Base Color=VALTORGB<MIX³<NOISE>>, Roughness=VALTORGB<...>, **Metallic=VALTORGB<INVERT<...>>**, Normal=BUMP<MIX⁴<NOISE>>; **Sheen Weight 0.2**; **mapping_scale (2, 11, 2)** — ยืดแกนเดียว 5.5:1 = ทิศด้าย/weave อยู่ใน mapping ไม่ใช่ใน texture
5. **Colorway = reuse mesh เป๊ะระดับทศนิยม 6 ตำแหน่ง**: vneck 3 สี verts 2,830 / area 1.509639 m² เท่ากันหมด, polo 3 สี 5,422 / 1.641729 — เปลี่ยนเฉพาะรูป Base_color (Rough/Metal/Normal ใช้ไฟล์ซ้ำ .001–.007)
6. **Origin ของ assembly = จุด function**: ทุก asset กลุ่ม garment_hung (10/10) มี EMPTY root — แต่ hanger เดี่ยว 2 ตัว (ce055de1, e4487f27) เป็น mesh เดียวไม่มี EMPTY; ใน 03ede500 ยอด hook อยู่ ~+26mm จาก origin ส่วนชายเสื้ออยู่ −1,123mm → origin ≈ แกนราว วางของ = วาง EMPTY บนราว (R9 ฉบับของเขา: contact เป็น datum ไม่ใช่เลข z ที่พิมพ์)
7. **ระยะประกอบหัวแขวน**: Δz(origin hook ↔ origin hanger) = 142.3mm (03ede500) / 139.4mm (91bbbed5, ef06e40e) — คงเส้นคงวา ~140mm; hook สูง 90.2mm; ถ้า origin อยู่กลาง bbox จะได้ ราวบน→สันบ่าไม้แขวน ≈ 113mm (สมมติฐานต้อง verify — ดูคำถามพิกเซล)
8. **วินัย texture**: BaseColor=sRGB, Rough/Metal/Normal/AO=Non-Color ถูก 100% ทุก asset; เสื้อ 4096², ไม้แขวน 2048² (ยกเว้น h_hanger_rough.jpeg ของ ce055de1 = 1024²); ป้าย care label ใช้รูปจิ๋ว 400×362 + Alpha จากรูปเดียวกันเป็น material slot ที่สอง (ef06e40e)
9. **แปลก**: vneck โหลด Mixed_AO 4096 มาแต่ไม่ได้ต่อสาย; maxi dress แพ็ค `bakedLight.png` (แสงอบใน asset); jacket/long-sleeve หมุนลูก 180° รอบ X ใต้ EMPTY (reuse ชุดเดิมพลิกซีก)

## กฎ transferable จัดอันดับ

1. **ไม้แขวนต้องเป็น MESH ไม้หนา ไม่ใช่ลวด CURVE** — pro 12/12 ใช้ mesh, ตัวไม้ 16.5–38.1mm หนา, งบแค่ 366–760 verts (+SUBSURF หรือ BEVEL weight-limit + WEIGHTED_NORMAL) ก็จบ. ของเรา 23 เส้นลวด ⌀3.6mm ล่องหนทั้งต่อ instrument (P2r-31) และเกือบต่อกล้อง. แก้ที่ `build_room.py:6288`: สร้าง wood-profile mesh (กติกา R8: box+radius = ปั้นได้ถูกกฎ)
2. **ก่อนตัดสิน asset ที่ซื้อ ให้เปิด `.orig.blend` ไม่ใช่ glb** — glb ทำลายหลักฐานแบบวัดได้: 5,200 quads→0, smooth 0.864→1.0, SUBSURF/procedural node หายเกลี้ยง. คำตัดสิน p2r86 ("การ์ดพับ") ลงโทษ asset จากร่างที่ถูก container บี้แล้ว. ประตู `_model_path` ควรมีทาง append จาก .blend (มีบนดิสก์อยู่แล้ว ห้ามลบตาม memory note)
3. **งบ verts เสื้อแขวน: cage 1.5–3.3k v/m², ทั้ง asset ≤5.5k verts** — สองทางถูกกฎ: quad cage (tris=0) + SUBSURF render2 + pin vertex group, หรือ mesh อบสำเร็จไร้ modifier. ที่ผิด: ไม่มีตัวไหนใช้ displacement (0%) ไม่มี shape keys
4. **ทิศด้ายอยู่ใน mapping ไม่ใช่ noise** — mapping_scale (2,11,2) = ยืด 5.5:1 ตามแกนผ้า + TEX_WAVE 1 ตัว. เพิ่ม 2 node นี้เข้า `_woven` (build_room.py:3004) แล้วผ้า procedural เลิกเป็น static; sheen ของ pro = 0.2 (เราตั้ง 0.4)
5. **ความหนาผ้า = SOLIDIFY 2.5mm offset −1 อย่างมาก หรือไม่มีเลย** — hem/collar/สาบกระดุมฝากไว้กับ normal map 4096 (ตระกูล baked) หรือ BUMP procedural (ตระกูล cloth-deco) ไม่ใช่ geometry; อย่าปั้นขอบผ้าด้วยมือ (R8 ห้ามอยู่แล้ว — นี่คือหลักฐานฝั่งซื้อว่าโปรก็ไม่ทำ)
6. **หัวแขวนเป็นตัวกำหนดช่องว่าง ไม่ใช่ reserve ที่พิมพ์** — hook 90.2mm + Δorigin 140mm สองเฟรมตรงกัน → ราว→บ่า ≈ 113mm ไม่ใช่ 150 (`_HANG_RESERVE`, build_room.py:6137); เปลี่ยนจากค่าคงที่เป็นค่าที่ derive จากขนาด hanger ที่ใช้จริง (R9: contact ไม่ใช่พิกัด)
7. **Colorway = mesh เดิม + สลับ Base_color รูปเดียว** — เขา stamp 3 สีจาก mesh ที่ area เท่ากัน 6 ตำแหน่งทศนิยม; ของเราตอนนี้ import ซ้ำจน texture 4096² บวม 69 ก้อนจาก 15 stems — dedupe images/mesh data ตอน import คือ lever VRAM ที่แทบฟรี
8. **ชิ้นเล็กหลอมใน mesh เดียวแล้วแยกด้วย material slot** — ce055de1 ใส่ hook+ไม้ใน mesh เดียว 699v สอง slot; ป้าย care label = material slot ที่สอง + รูป 400×362 alpha (ef06e40e). ลด object count โดยไม่เสีย material boundary (ตัวที่ทำให้ R10 อ่านของออก)

## คำถามที่ต้องพิสูจน์ด้วยพิกเซล

1. **ตระกูล cloth-deco render จาก `.orig.blend` (SUBSURF r2 + Procedural Fabric) จะเลิกอ่านเป็น "การ์ดพับ" ตาม p2r86 ไหม?** — dump ชี้กลไกครบ แต่คำตัดสินสุดท้ายเป็นของเฟรม (R5 playblast ใหม่บนร่าง append-from-blend). นี่คือ negative/positive control ของ D2-D3 ทั้งคู่
2. **เสื้อ cloth-deco เป็นผิวเดียวหรือประกบสองหน้า?** area 1.458–1.696 m² ต่อตัว บอกไม่ได้ว่านับสองหน้าหรือกางแขน — ต้อง probe ลึก (backface หรือ x-ray crop)
3. **ราวบน→บ่าไม้แขวน ≈113mm** อิงสมมติฐาน origin=กลาง bbox (จริงสำหรับ hook/hanger, พังสำหรับเสื้อ — เสื้อ 03ede500 origin ไม่อยู่กลาง bbox แน่เพราะ top จะห่างราว 424mm ซึ่งเป็นไปไม่ได้) — ต้องวัดจาก render หรือ bbox world จริง
4. **uv_layers=2 บนเสื้อ+ไม้แขวน 03ede500 ใช้ทำอะไร** ในเมื่อ material เป็น procedural ล้วน (ไม่ต้องใช้ UV เลย)? สันนิษฐานได้แค่ bake target — dump ไม่มีคำตอบ
5. **272 tris + smooth 0.864 ของ polo = กระดุมปั้นจริงไหม?** ต้อง crop ดูแนวสาบ; ถ้าจริง แปลว่า "ของแข็งบนผ้า" เขาก็ยังปั้นเป็น geometry ไม่ฝากใน normal map
6. **Metallic บนผ้า** — pro ป้อน ramp inverted เข้า Metallic (procedural) และรูป Metallic เข้าเสื้อ baked; ค่าในรูปเป็นศูนย์ทั้งภาพหรือมี accent (ซิป/กระดุม)? ตัดสินไม่ได้จาก dump; ห้ามลอกจนกว่าจะเปิดรูปดู
