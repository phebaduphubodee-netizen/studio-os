## Row contract (the ```ledger block is the machine surface)

    <unit path> :: <verdict> :: <successor(s) ;; …> :: <pin ;; pin ;; pin> :: <rationale>

- A PIN is a literal string from the STAGED SOURCE proven present in a named
  successor. Pins were chosen before opening the successor and never swapped
  to fit; a pin that failed measurement moved the row to PARTIAL and is named
  in the rationale as `MISSING (measured <date>)` — the miss is the record.
- DROPPED requires a rationale naming what was checked. OWED = real value,
  promotion still owed (declared debt, distinct from "nobody looked").
- Unit identity: a Discord unit is the THREAD DIRECTORY. Attachment binaries
  (`files/`, `_external-fetched/`, `raw.json`) are payload, never units.
- `sources-manifest.md` + the five `qa-history.json` are PROVENANCE files
