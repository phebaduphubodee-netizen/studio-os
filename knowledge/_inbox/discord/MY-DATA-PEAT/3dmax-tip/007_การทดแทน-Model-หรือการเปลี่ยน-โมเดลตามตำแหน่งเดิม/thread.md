> embed: The Substitute Modifier | 3ds Max tutorial — https://www.youtube.com/watch?v=8g6Uc0QWAYs — With the built-in Substitute modifier you can quickly replace one object with another.

Instructions:
1) Select the object(s) you want to replace.
2) Apply the Substitute modifier.
3) In Substitute Assignment, select the object to replace.

In order to work correctly, the object must be a single one (all elements are attached).
