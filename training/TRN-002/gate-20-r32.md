### วิธี derive: ใช้เฟรมของเราเป็นเครื่องวัดแสง

เฟรมเราเป็นภาพเดียวที่ **รู้ albedo แน่นอน** → irradiance ที่วัตถุ = Y_ours / albedo
→ อ่านพิกเซลของเป้าผ่าน irradiance ของเรา = albedo ที่ผิวของเป้าต้องมี
ยึดกับ `paint_white` (ผิวอ้างอิง phase-2, n=65,014 px, แถวเดียวในตารางที่ไม่ได้มาจาก
อัตราส่วนของอย่างอื่น) → `k = (target_mean/ours_mean) / 1.10952`

## เครื่องมือพัง 3 จุด และทั้งสามจุดเงียบ ไม่มีอันไหน "fail"

**1. เครื่องมือนี้ไม่ได้ถูกรันมาตั้งแต่ r27** — id mask เป็นขั้นตอนแยกที่ต้องสั่งเอง
r28/r29/r30/r31 ไม่มีเลย → **สี่รอบติดที่ metric หลักของเลนหายไปทั้งตัว** และไม่มี gate
ไหนสังเกต เพราะ **metric ที่ไม่มีใครคำนวณ ไม่ได้รายงานว่าล้มเหลว มันไม่รายงานอะไรเลย**

**2. px weighting ซ่อน error ไปครึ่งหนึ่ง** — ผนัง/ฝ้า/ตู้กินพิกเซล ~62% ของกองที่เชื่อถือได้
วัดบน artifact ของ r27 เอง ไม่ต้องเรนเดอร์ใหม่: **SHAPE 0.2000 (ถ่วง) เทียบ 0.3359 (ไม่ถ่วง)**
→ metric ที่ถ่วงด้วยพิกเซลตอบว่า *"เฟรมถูกไปกี่ส่วน"* ไม่เคยตอบว่า *"ของแต่ละชิ้นถูกมั้ย"*
และ "ทุกชิ้นเป็นพลาสติกขาวเนื้อเดียว" เป็นคำกล่าวเรื่อง **ชิ้น**

**3. วัตถุสามชิ้นล่องหนจากทุกการวัดที่เลนนี้เคยทำ** — id mask คัดด้วย substring
`SM_TRN002_` แต่ cloth solver ตั้งชื่อ `duvet` / `throw_woven` / `throw_velvet` เปล่า ๆ
→ **ผ้านวม — ชิ้นที่ triage เองชี้ว่าเป็นของสว่างที่สุดในภาพเป้า — ไม่เคยปรากฏใน ladder
สักแถวเดียวใน 31 รอบ** ไม่มีอะไรพัง: **filter ที่ match ไม่เจอ ก็แค่คืนแถวน้อยลง**
→ ซ่อมสองชั้น: ตั้งชื่อให้ตรง convention **และ** `absent_from_mask()` รายงาน mass ที่
mask มองไม่เห็น (ไม่ใช่ allowlist — spec รู้อยู่แล้วว่ามีอะไร)
