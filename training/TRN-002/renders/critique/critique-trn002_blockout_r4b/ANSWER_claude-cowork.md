## Q1 — ยังเพี้ยนตรงไหน เรียงตามที่ทำร้ายภาพมากสุด

รายการรอบนี้สั้น และผมตั้งใจให้มันสั้นตามที่ตาเห็นจริง — ไม่ยืดเพื่อรักษาฟอร์ม:

**1. ผ้านวมพับปลายเตียง: โปรแกรมประกาศ "ผ้านวมพับพาด" แต่ในภาพแทบไม่มีมวล**
- (a) ปลายที่นอนฝั่งใกล้ (ล่าง-กลางของเตียง) — เห็นเพียงรอยยกบาง ๆ เส้นเดียวพาดขวาง แทบกลืนไปกับผิวที่นอน
- (b) ผ้านวมพับจริงคือมวลนุ่มหนาเป็นชั้น อย่างต่ำ ~80–150mm พร้อมเงาใต้ชายที่ม้วนตกขอบข้าง — ใน clay ที่แสงแบบนี้ ความหนาระดับนั้นต้องอ่านเป็น step เงาชัด สิ่งที่เห็นตอนนี้อ่านเป็น "ผ้าคลุมรัดแน่น" ไม่ใช่ "ผ้านวมพับหนา" ปลายเตียงเลยดูโล่งผิดปกติสำหรับภาพขายห้องนอน
- (c) โปรแกรมข้อความเอง + ตรวจความหนาจริงของ object จากไฟล์ฉากได้ทันที — ถ้าไฟล์บอกหนา ≥80 แต่ภาพอ่านแบน = ปัญหาอยู่ที่ทรง/ขอบของก้อน ไม่ใช่ตาผม

**2. ดาวน์ไลท์: นับได้ชัด ๆ อย่างน้อย 5 จุด (อ่านได้ 5–6) vs โปรแกรม "4 จุด ไม่มีไฟฝ้าชนิดอื่น" — รอดมารอบที่สี่**
- (a) ฝ้า: มุมซ้ายบน 1, ซ้ายกลาง 1, กลางเฟรม 2, ใกล้ bulkhead 1(–2)
- (b) รอบนี้โปรแกรมปิดทางหนีแล้ว ("ไม่มีไฟฝ้าชนิดอื่น") — จำนวนที่เกินจึงไม่มีคำอธิบายเหลือ นอกจาก มวลเกินจริงในฉาก หรือ โปรแกรมเขียนน้อยกว่าของจริง อย่างใดอย่างหนึ่ง ต้องจบรอบนี้
- (c) นับ object บนฝ้าจากไฟล์ฉากครั้งเดียว — ข้อนี้เป็น binary แล้ว ไม่มีที่ว่างให้ taste

**3. [verify] เก้าอี้เครื่องแป้ง: มุมกล้องนี้เห็นแค่เศษมวลเตี้ย ๆ — ยืนยันไม่ได้ว่าครบสเปก**
- (a) หน้าโต๊ะ (ซ้ายกลางเฟรม) — เห็นมวลเตี้ยบางส่วนถูก run โต๊ะบัง
- (b) สเปกประกาศ ที่นั่ง 0.45 พนัก 0.78 — จากภาพผมยืนยันได้แค่ว่า ก้อนตันสูง ของรอบก่อนหายไป แต่ยืนยันไม่ได้ว่าเก้าอี้ตัวจริงครบ (ที่นั่ง+พนัก) และถ้ากล้องถูก solve จาก target แล้วภาพอ้างอิงเห็นเก้าอี้ชัดกว่านี้ ตำแหน่ง/ขนาดของเราอาจคลาด
- (c) ปิดด้วยมิติ+ตำแหน่งจากไฟล์ฉาก แล้วเทียบการมองเห็นกับ target ในเครื่อง

**ข้อสังเกตไม่จัดอันดับ [opinion — โปรแกรม list เป็นสมมติฐานเอง]:** bolster วางค่อนซ้ายและสั้น (~1/3 ความกว้างเตียง) — ทางเลือก styling ที่มีจริง แต่ให้เทียบความยาว/ตำแหน่งกับ target ตามที่ addendum เปิดช่องไว้

## Q2 — ทิศทางแก้เชิงสัดส่วน

- ผ้านวม: ก้อนพับหนาจริง ~100–150 ชายม้วนตกขอบที่นอนสองข้าง กว้างพาดเต็มหรือเกือบเต็มความกว้างที่นอน เงาใต้ชายต้องเกิด
- ดาวน์ไลท์: ตัดสินให้จบ — 4 ตามโปรแกรม หรือแก้โปรแกรมให้ตรงของจริง แล้ว pin กันข้อนี้โผล่รอบที่ห้า
- เก้าอี้: ยืนยันที่นั่ง 0.45 / พนัก 0.78 / ระยะสอดใต้โต๊ะ (ช่องว่างใต้ 0.875 เหลือพอเข่า)

## Q3 — เพี้ยนเพราะ clay ไม่ใช่เรขาคณิต

- ผิวเรียบของหมอน/bolster/ผ้านวม (รอยยับ ผิวผ้า) — เฟสผ้า/วัสดุ; แต่ **ความหนา-มวลของผ้านวม (ข้อ 1) เป็นเรขาคณิต** อยู่เฟสนี้
- ความมืดหลัง partition / ช่องชั้นตู้โค้งเงาดำสนิท / โคมโป๊ะยังไม่ให้แสง — เฟสแสง
- ผิวพื้น พรม ลายไม้ — เฟสวัสดุ

## Q4 — อาการรอบก่อน หายหรือยัง

- แคปซูลตั้ง + ก้อนขั้นบันไดที่หัวเตียง → **หาย**: โซนหัวเตียงตอนนี้อ่านออกทันทีเป็น หมอนพิงเอียงสองใบ (เอน ~20–25°) + bolster — ตรง trio ของโปรแกรม
- bolster หาไม่เจอ → **เจอแล้ว**: ทรงกระบอกนอนหน้าหมอน หัวตัดกลมชัด Ø อ่านได้ ~0.18–0.2
- เก้าอี้ตันสูง → **ก้อนสูงหายแล้ว** แต่ตัวเก้าอี้จริงติด [verify] ตามข้อ 3
- ตู้ชั้นโค้งตัน → **หาย**: เห็นช่องชั้นเปิดสองช่องที่ตู้มุม ตรงแนว z ที่วัดประกาศ

## หมายเหตุนอกกรอบ critic — ถึง ledger

รอบนี้ผมตัดสินว่า **โซนที่เถียงกันสองรอบ (หัวเตียง) ปิดแล้ว** และของที่เหลือเป็น binary-measurable สองข้อ + verify หนึ่งข้อ ไม่ใช่คำตัดสิน "ยังไม่ปิด" แบบรอบก่อน — บันทึกไว้เพื่อ calibration ของ rung นี้เอง: critic ที่พูดได้แต่ "ยังไม่ผ่าน" ไม่ใช่เครื่องมือวัด มันคือค่าคงที่ ตาผมว่าไม่ผ่านเมื่อไม่ผ่าน และว่าปิดเมื่อปิด — รอบนี้คือแบบหลัง
