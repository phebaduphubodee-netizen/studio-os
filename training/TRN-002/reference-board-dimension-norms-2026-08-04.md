## Class 1 — platform bed หุ้มผ้า (ข้อค้าง r2b #3)

- เฟรม/แท่นมาตรฐาน: **12–18 นิ้ว (305–457mm)** จากพื้นถึงหลังแท่น; ที่นอนหนา
  10–14 นิ้ว → **ผิวบนที่นอนรวมช่วงมาตรฐาน US ≈ 560–810mm** โดยดีไซน์
  low-profile "hug the floor" อยู่ปลายล่างของช่วง
  — [Mattress Firm: Platform Bed Height](https://www.mattressfirm.com/shop/platform-bed-height)
- **ผลต่อ triage r2b:** ตัวเลขนี้ ทำให้ข้อ 3 ของ C2 อ่อนลงครึ่งหนึ่ง — ผิวบน
  ~650–700 ที่อ่านจากภาพ "อยู่ในช่วงมาตรฐาน" ไม่ใช่ผิดสัมบูรณ์; สิ่งที่ต้องตัดสิน
  ด้วย target ในเครื่องคือคาแรกเตอร์ low-profile หรือไม่ ส่วน "ฐานยื่นเป็นชาน vs
  ฐานหุบ recess" เป็นประเด็นเรขาคณิตแยกต่างหากที่ยังยืน

## Class 2 — nightstand ลอย (ข้อค้าง r2b #2)

- ตัวอย่างสเปกจริงของ floating nightstand เชิงพาณิชย์: **H 152 × W 502 ×
  D 387mm** (ตัวกล่องเตี้ย — ความสูงใช้งานมาจากระดับที่แขวน ไม่ใช่ตัวกล่อง)
  — [Dimensions.com: Lenia Floating Nightstand](https://www.dimensions.com/element/lenia-nightstand-floating)
- แนวปฏิบัติ designer ที่ยังไม่มี web source ใน board นี้ **[practice — หา
  source เพิ่มได้]**: แขวนให้ผิวบนอยู่ระดับ ±50mm ของผิวบนที่นอน → กับที่นอน
  ~550–650 ผิวบน nightstand ควร ~500–650 สอดคล้อง band 0.9m ของโปรแกรม
  (nightstand ต่ำกว่า band ชัดเจน อ่านเป็นชั้นลอยใต้คิ้ว)

## Class 3 — TV ในห้องนอน (มิติ "สมมติฐาน" ของ addendum โดยตรง)

- ดูจากเตียง (พิงหมอน): กึ่งกลางจอ **48–60 นิ้ว (1220–1525mm)** สูงกว่านั่งโซฟา
  มาตรฐาน (42 นิ้ว / 1067mm) ราว 150–450mm เพราะ eye level ตอนพิงสูงกว่า
  — [Mount-It: Ideal TV Mounting Height](https://www.mount-it.com/blogs/articles/ideal-tv-mounting-height)
- **ผลต่อ triage:** ข้อสงสัย "TV ติดสูง" ของ C2 ทั้ง r1/r2b ต้องตัดสินด้วยเจตนา
  การใช้งาน — ถ้าจอนี้ดูจากเตียงเป็นหลัก กึ่งกลาง ~1400–1500 คือถูกตาม norms
  ไม่ใช่ defect; ถ้าดูจากเก้าอี้โซนซ้าย ค่อยดึงลง → เช็กกับ target ว่าจอ
  ในภาพอ้างอิงอยู่ระดับไหน แล้วปักตามนั้น

## Class 4 — ดาวน์ไลท์ฝัง (ข้อค้าง r2b #5)

- ระยะห่างดวง rule of thumb = **ความสูงฝ้า ÷ 2** → ฝ้า 3.1m ≈ ระยะดวง ~1.5m
  on-center; ระยะจากผนัง **0.6–0.9m** กันเงาเลอะผนัง
  — [Take Three Lighting: Layout Downlights](https://www.takethreelighting.com/layout-downlights-general.html)
- **ผลต่อ triage:** โปรแกรมระบุ 4 ดวง — กับ zone เตียง+ทางเดินของห้องนี้
  ระยะ ~1.5m ให้ราว 4–6 ดวงพอดีช่วง ดังนั้น "4" ของ reference คือการออกแบบ
  spacing กว้าง + งานไฟอื่นอยู่ที่ bulkhead/หิ้ง — จำนวนที่นับได้ ~6–7 ในเรนเดอร์
  ยังต้องเคลียร์: ดวงไหนคือดาวน์ไลท์จริง ดวงไหนคือชนิดอื่น แล้วชนกับ 4 ของโปรแกรม
