CONTEXT: An interior studio working in the Thai market needs SOURCED colour and
reflectance anchors for a cream / oak / black palette, to replace design-intent
values that were chosen by eye and have never been traceable to a measurement. A
ΔE00 gate exists and has never scored, because the anchor file it consumes has
never been written. Numbers without a source URL are quarantined and do not enter
the knowledge base — please respect that: a URL per value or an explicit
"NO SOURCED VALUE FOUND".

QUESTIONS:

1. For Thai-market interior emulsion lines (TOA, Beger, Jotun Thailand, Nippon
Paint Thailand), which published cream / off-white colour codes carry manufacturer
LRV values in roughly the 75–90 band, and what are the exact LRV and hex/sRGB (or
NCS) values per code? Give the manufacturer page URL each value came from.

2. What is the published relationship between paint LRV and CIE luminance Y /
linear reflectance, and the accepted procedure to derive an sRGB base-colour triple
from an LRV plus a hue description? Cite the formula's source (standard, paper, or
manufacturer technical note), including the sRGB transfer function used.

3. What base-colour ranges (sRGB or CIE L*a*b*) and roughness ranges do scan-based
PBR material libraries and published references report for white/European oak
veneer under (a) clear matte lacquer and (b) hardwax oil? Source URL per value.
Name the libraries.

4. What 60° gloss-unit bands do architectural powder-coat suppliers publish for
matte, satin and gloss black, and is there any sourced conversion from gloss units
(GU at 60°) to a microfacet/GGX roughness value? If the conversion exists only as
practitioner rule-of-thumb, say so and give the strongest published form of it.

5. What measured complex refractive index (n,k) or F0 values exist for brass —
polished vs brushed/satin — and what base colour, roughness and anisotropy ranges
do measured material libraries publish for satin brass hardware? Source URL per
value; name the measurement database.

6. What L* / sRGB band do measured references give for architectural powder-coat
black and near-black factory finishes? Is there published support for a
reflectance FLOOR — i.e. that real black finishes do not go below some sRGB value —
and what is that value?

7. What batch-to-batch and inter-sheen colour tolerance (ΔE00 or ΔE*ab) do interior
paint manufacturers publish or accept? This calibrates whether a pass ≤1.0 /
warn ≤2.0 gate against a swatch-derived anchor is achievable in practice or is
tighter than the industry's own tolerance.

8. Do any of the Thai brands above publish spectral or colorimetric data (L*a*b*,
LRV) in a machine-readable form — a downloadable fan-deck data file, an API, or a
colour-tool export? Name the exact URL if so.
